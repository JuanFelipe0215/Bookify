# Bookify

Sistema de gestión de libros desarrollado con ASP.NET y arquitectura limpia MVC.

## Tecnologías
- ASP.NET Core
- C#
- SQL Server
- Entity Framework
- Docker
- Tailwind CSS

## Características
- CRUD de libros
- Gestión de usuarios
- API REST
- Arquitectura por capas
- Validaciones
- Autenticación

## Arquitectura
- Controllers
- Services
- Repository
- Data
- Models
